# Archived v1 experiments

These configurations and launchers are preserved for provenance only. They use
the legacy schema and are not compatible with the DRAGN v2 training pipeline.

Where a YAML-to-Slurm mapping was explicit, both files were renamed to
`config.yaml` and `run.sbatch` inside one experiment directory. Ambiguous
configs and non-training utility launchers are retained under `unmatched/` with
their original filenames.
